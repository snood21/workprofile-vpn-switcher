# Как помочь проекту

## Язык

Issues и pull request'ы можно писать на русском или английском языке — оба одинаково приветствуются.

## Баг-репорты

Пожалуйста, указывайте:
- модель устройства и версию ОС/прошивки (особенно для кастомных сборок — MIUI, HyperOS, EMUI и т.д.);
- какое приложение используется для управления рабочим профилем (Shelter и т.п.);
- какой VPN-клиент используется;
- шаги для воспроизведения;
- логи приложения, если они включены в настройках (Расширенные настройки → Логирование).

## Pull request'ы

- Описывайте, что и почему меняется.
- Если изменение затрагивает пользовательский интерфейс — приложите скриншоты (для обеих тем, если затронуты обе).
- Изменения в строках ресурсов (`strings.xml`) нужны для обоих языков — `values-ru` и `values-en`.

# Contributing

## Language

Issues and pull requests can be submitted in English or Russian — both are equally welcome.

## Bug reports

Please include:
- device model and OS/firmware version (especially for custom ROMs — MIUI, HyperOS, EMUI, etc.);
- which app manages the work profile (Shelter, etc.);
- which VPN client is used;
- steps to reproduce;
- app logs, if enabled (Advanced settings → Logging).

## Pull requests

- Describe what changes and why.
- If the change affects the UI, attach screenshots (for both themes, if both are affected).
- Changes to string resources (`strings.xml`) need updating for both languages — `values-ru` and `values-en`.
